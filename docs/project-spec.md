# 專案規格與作業要求對照

確認日期：2026-11-14。站名：瑯琊榜人物誌。類型：主題介紹網站。

## 目前延伸版本

2026-11-14 使用者要求依既有規則新增靖王介紹。本份上傳包已完成靖王詳細頁，現在為 4 頁、12 位角色、2 位完整角色介紹。以下首版界線保留為新增前的基準，後續擴充依既有規則進行。續作證據見 `ai-continuation.md`。

## 已確認範圍

- 首頁顯示 12 位人物的圖片與基本介紹，只有梅長蘇有完整角色頁。
- 首版完成梅長蘇角色頁與太子被廢事件頁，兩條內容線各有一篇完整示例。
- 角色提供不劇透與劇透介紹；事件屬劇透內容。首頁預設隱藏事件名稱。
- 文字依小說，不做心理分析；電視劇圖片只作視覺素材。
- 米白、墨色、朱紅的沉靜古風。手機與桌面共用內容。
- 原圖與原文留在既有資料夾。使用者自行上傳與公開網站。
- 後續延伸靖王等角色、譽王叛亂等事件；目前不完成全部題材。

## 作業各項要求對應

| 作業要求 | 本專案的實際對應 |
| --- | --- |
| 自己的小專案與目的 | 小說角色與事件介紹；首頁可直接閱讀 |
| AGENTS.md | 根目錄 AGENTS.md，先制定後開發 |
| 整體風格 | 共用 web/styles.css 與 AGENTS.md 第 7 節 |

| 命名及放置 | AGENTS.md 第 2、3 節與實際目錄一致 |
| AI 修改規則 | 來源核對、劇透界線、草稿、共用樣式、修改與檢查流程 |

## 狀態判定

本機網站、文件及驗證完成，不等於已完成公開發布。只有取得可匿名瀏覽的 GitHub Repository 與網站網址，才可將作業的公開發布項目標為完成。9–10 分是本專案的設計目標，最終評分由授課者決定。
